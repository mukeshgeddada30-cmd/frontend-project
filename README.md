# TaskFlow

A clean, responsive task-management dashboard built with **HTML, CSS and vanilla JavaScript**.

## ✨ Features

- Create, edit and delete tasks
- Mark tasks as completed
- Search tasks instantly
- Filter by All, Active and Completed
- Sort by newest, oldest, priority or title
- Task categories and priorities
- Due dates
- Completion statistics
- Dark/light mode
- Responsive layout
- Persistent data with `localStorage`
- No frameworks or build tools required

## 🚀 Run locally

1. Download or clone this repository.
2. Open `index.html` in your browser.

For the best development experience, use VS Code with the **Live Server** extension.

## 🛠 Tech

- HTML5
- CSS3
- JavaScript (ES6+)
- LocalStorage API
